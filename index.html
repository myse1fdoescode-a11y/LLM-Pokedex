Searching

Search for Pokémon

  • Enter a Pokémon name or Pokédex number, then select Search.
  • Leave the search box empty to browse all Pokémon.
  • Select type icons to filter your results.

Browse results

  • Use Previous and Next to move between result pages.
  • Select a Pokémon card to open its Pokédex entry.

Use the Pokédex

  • Use the arrows to view the previous or next Pokémon.
  • Select the species description to expand or collapse it.
  • Select Exit to return to your results.

Press the 'Confused?' button to view these instructions any time.
